5. RESTRICCIONES ÚNICAS
═══════════════════════════════════════════════════════════════════════════════════

• Disponibilidad: (HabitacionID + Fecha) ÚNICA
  └─ No puede haber 2 registros de disponibilidad para la misma habitación y fecha

• Reserva: (ClienteID + HabitacionID + Fecha) ÚNICA
  └─ Un cliente no puede reservar la misma habitación en la misma fecha dos veces

• TipoHabitacion.Nombre: ÚNICO
  └─ No puede haber tipos de habitación con el mismo nombre

• Habitacion.Codigo: ÚNICO
  └─ Cada habitación tiene un código único (S101, D201, U301, etc)

• Usuario.NombreUsuario: ÚNICO
  └─ Cada usuario tiene un nombre único para login

• Cliente.Identificacion: ÚNICA
  └─ Cada cliente tiene una identificación única (cédula/pasaporte)
